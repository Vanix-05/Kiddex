# Kiddex
A gamified learning platform with customizable virtual pets and AI-assisted educational mini-games.

## Run it locally
1. First time (or after pulling new packages): `npm run setup` in the repo root installs the root, backend and frontend packages.
2. `npm run dev` in the repo root starts the backend (label **api**) and the frontend (label **web**) together.
3. Press Ctrl+C once to stop both.
